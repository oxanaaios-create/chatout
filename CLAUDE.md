# Правила для Claude

Сначала прочитай README.md: там роутер «задача → файлы».

## Начало сессии
1. Прочитай PROJECT.md, docs/plan.md, два последних файла docs/devlog/ и последние 10 записей docs/decisions.md.
2. Если файла лога за сегодня нет — `npm run devlog`.
3. Сверь план дня с docs/plan.md. Задачу без критерия приёмки не начинай: сначала допиши критерий.

## Во время работы
- Каждое решение сразу в docs/decisions.md в формате таблицы файла.
- Значения дизайна только из visual/tokens.css. Новое значение: правка visual/visual-system.json → `npm run tokens`.
- Нет факта — `[DATA NEEDED]`, не выдумывай.
- Грузи файлы по _retrieval-rules.yaml, а не всё подряд.

## Конец рабочего дня (обязательно)
1. Заполни docs/devlog/<сегодня>.md: итог одной строкой, сделано со ссылками на файлы, решения, блокеры, план на завтра с критериями приёмки.
2. Обнови статусы в docs/plan.md.
3. `npm run day -- "<итог дня одной строкой>"` — проверки, коммит, push.
4. Если проверки упали — исправь причину, не обходи проверку.

## Нельзя
- Коммитить .env, ключи, токены, пароли.
- Переписывать историю main (force push).
- Удалять записи из decisions.md и devlog: только дополнять.
