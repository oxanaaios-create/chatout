# Рецепт: кейс для Behance

Запускается только по команде «кейс».

Сюжет из `research/`, `docs/decisions.md`, `docs/devlog/`: задача → инсайт → 3–5 решений (до / после / почему) → система (дерево кита, токены, правила) → применения → результат.

Выход: `outputs/behance/` — модули 1400px (HTML на токенах бренда → PNG), описание на 120 слов, 3 варианта обложки.

## Критерии приёмки
- 8–14 модулей в порядке сюжета
- только реально сделанные выходы, без фейковых мокапов и выдуманных метрик
- концепт реального бренда помечен «Unofficial concept» на обложке
- текст голосом дизайнера, а не бренда
