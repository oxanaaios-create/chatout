# Рецепт: брендбук

1. Источник — только кит: `verbal/`, `visual/`, `assets/`.
2. Каждое правило: пример на живых токенах + пример «не так».
3. Разделы: стратегия, голос, цвет, типографика, сетка, знак, арт-дирекшн, компоненты.
4. Выход: `outputs/brandbook/` (HTML с экспортом в PDF).

## Критерии приёмки
- в брендбуке есть каждое правило кита
- нет правил, которых нет в ките
- у каждого правила есть пример и анти-пример
