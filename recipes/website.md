# Рецепт: сайт

1. Прочитать файлы из `_retrieval-rules.yaml → website.loads`.
2. План секций до кода: секция → её одна задача → правило кита (файл + правило), на которое она опирается. Утвердить.
3. Код только на `site/styles/tokens.css`. Новое значение — сначала в `visual/visual-system.json`.
4. В hero оставить слот `<!-- MAGIC_TRICK -->` под идею из `magic_trick.md`.
5. Состояния интерактивных элементов: default, hover, focus-visible, disabled, loading.
6. QA: `npm run check`, 390 / 768 / 1440px, пункты `evals/quality-bar.md`.
7. Вернуть список GAP: всё, что пришлось угадать. Каждый GAP превращается в правило кита.

## Критерии приёмки
- `npm run check` — 0 ошибок
- 390px без горизонтального скролла
- все пункты quality-bar: pass или объяснение
- список GAP пуст или превращён в правила
