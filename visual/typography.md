# Типографика

Жёсткие рамки: 4–5 размеров, минимум 14px, всё кратно 2px, не больше 2 гарнитур и 3 начертаний.

| Токен | Размер / интерлиньяж | Где | Где нет |
|---|---|---|---|
| s | 14 / 20 | подписи, мета | основной текст |
| m | 16 / 24 | основной текст | заголовки |
| l | 20 / 28 | лид, подзаголовки карточек | |
| xl | 28 / 32 | заголовки секций | |
| 2xl | 40 / 44 | hero | больше одного раза на экран |
